# AegisQ Presentation — GitHub Pages Slideshow

This folder contains a web slideshow made from the six slides in `AegisQ_slide_presentation.pptx`.

## Publish it on GitHub Pages

1. Extract this folder from the ZIP file.
2. Create a new GitHub repository, for example `AegisQ-Presentation`.
3. Upload **all contents inside this folder** to the repository's top level. Make sure `index.html` is at the repository root, and keep the `slides` folder beside it.
4. Open the repository on GitHub and go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. After GitHub Pages publishes the site, the slideshow link will be:

   `https://YOUR-USERNAME.github.io/AegisQ-Presentation/`

   Replace `YOUR-USERNAME` with your GitHub username. If you use a different repository name, replace `AegisQ-Presentation` too.

## Slideshow controls

- **Right arrow / Space / Page Down:** next slide
- **Left arrow / Page Up:** previous slide
- **F:** toggle full screen
- **Home / End:** first / last slide
- On a phone or tablet, swipe left or right.
- The **PPTX** link downloads the original PowerPoint file.

The web version displays each slide as a high-resolution image to preserve its layout. PowerPoint animations, transitions, embedded media, and editable slide elements are not reproduced in this web viewer.
