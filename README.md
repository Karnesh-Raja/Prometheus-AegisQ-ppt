# AegisQ Presentation — GitHub Pages Slideshow

## Slideshow controls

- **Right arrow / Space / Page Down:** next slide
- **Left arrow / Page Up:** previous slide
- **F:** toggle full screen
- **Home / End:** first / last slide
- On a phone or tablet, swipe left or right.
- The **PPTX** link downloads the original PowerPoint file.

The web version displays each slide as a high-resolution image to preserve its layout. PowerPoint animations, transitions, embedded media, and editable slide elements are not reproduced in this web viewer.
